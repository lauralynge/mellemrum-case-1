# Mellemrum

Mellemrum er en React-prototype for en lokal kultur- og eventplatform. Projektet er startpunktet for Case 1 i Product Optimization.

Den primære målgruppe er personer, der ønsker en enkel vej til at opdage og tilmelde sig lokale kulturoplevelser i Aarhus. Arrangører er en sekundær målgruppe, som bruger platformen til at dele events og få overblik over tilmeldinger.

## Funktioner

Brugeren kan:
- se kommende events
- søge efter titel, beskrivelse eller sted
- filtrere events efter kategori
- åbne en side med detaljeret information om det enkelte event
- udfylde en tilmeldingsformular
- læse mere om Mellemrum

Der findes desuden en intern side, hvor arrangører kan se en oversigt over tilmeldinger.

## Teknologier

Projektet er bygget med:
- React
- Vite
- React Router
- JavaScript
- HTML og CSS
- Supabase REST API
